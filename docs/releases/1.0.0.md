# Icod.Dedit 1.0.0

Icod.Dedit is a tabbed, modeless terminal text editor delivered as the
`dedit` .NET tool. It targets .NET 8, 9, and 10 and uses Icod.Widgets 1.8.0.

## Highlights

- Open several paths in independent tabs with per-document caret, selection,
  undo history, and safe close decisions. New, Open, Save, Save As, Save All,
  Close, Close All, and Exit are available from the File menu.
- Edit Unicode text with mixed line endings preserved. Copy/Cut without a
  selection uses the current logical line; a local linewise Paste inserts
  before the current line. Search supports literal and bounded .NET regex
  queries, replacement, wrap, and one-step undo for Replace All.
- Choose strict UTF-8 or BOM-marked UTF-8/UTF-16 output, convert LF/CRLF/CR
  line endings explicitly, and set per-tab indentation and word wrap.
- File saves use a same-directory temporary file and check the disk target
  for changes. Reload/Keep and Yes / Don't Save / Cancel decisions keep the
  editor buffer available when a conflict or cancellation occurs.
- Dirty Close, Close All, and Exit decisions use a red warning dialog with
  Y/N/C shortcuts and Cancel selected by default. Clean documents close without
  a prompt. Pointer clicks and keyboard choices use the same save, discard, or
  retain policy.
- Navigate menus by keyboard or pointer, including Alt mnemonics, nested
  overlays, and clickable dialog actions. Text selection drags request motion
  only while a mouse button is held and survive ordinary redraws. Menu clicks
  survive intervening presentation updates and unchanged layout passes;
  mouse Edit commands and Ctrl+V share the focused editor route.
  Pasting identical text over a selection collapses it at the resulting caret
  without changing document revision or adding undo history;
  selected text uses an explicit contrasting color and `SEL` indicator, while
  the terminal caret tracks the active text control and insert/overwrite mode.
- Read fixed line numbers in a decorative gutter with a themed current-line
  band; wrapped continuation rows retain that styling without repeating the
  number; decorative gutter clicks leave the caret and selection unchanged;
  and narrow viewports suppress the gutter so text keeps the last available
  column.
- Move Up, Down, Page Up, and Page Down through wrapped visual rows while
  retaining the preferred visual column across short rows. The status row
  continues to report the real logical line and character position rather
  than screen-row coordinates.

## Install and run

```text
dotnet tool install --global Icod.Dedit --version 1.0.0
dedit --help
dedit "first file.txt" "second.txt"
```

A .NET runtime matching the chosen target is required. The tool runs in an
interactive terminal. See the [README](../../README.md) for commands,
file-format behavior, and terminal requirements. The [changelog](../../CHANGELOG.md)
contains the complete development and release history.
